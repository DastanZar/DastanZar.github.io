approach

How a claim becomes credible here.

Every repo follows the same contract so numbers can be compared side by side.

01

Fresh core, tests first

Small, single-purpose kernels with unit tests that encode the theorem. No silent forks - prior art is credited in every README.

02

A real application layer

Each repo ships an app or demo bundle you can run, not just a notebook. Receipts come from executing that code.

03

Receipts, not screenshots

receipts/*.json holds numbers, charts are derived from them, CI pins them. Drift fails the build.

04

CPU honestly

No GPU numbers are ever asserted. Grading runs in CPU mode; absolute figures are reported as measured, relative when graded.
